# Backup Manager

A Django-based web application designed to manage data backups between local storage and Google Drive. The project focuses on providing a centralized hub for data protection and system monitoring.

## My Role: Frontend & UI Lead
As the lead for the presentation layer, I was responsible for the end-to-end design and implementation of the user interface (UI) and user experience (UX).

### Key Contributions:
* **Interactive Dashboard Design:** Developed the main monitoring hub, including visual indicators for system status (Engine, Scheduler, Database) and storage statistics.
* **Configuration Interface (Prototype):** Designed functional mockups for scheduling backup frequency and configuring automated e-mail notifications.
* **Backup Management Workflow:** Implemented intuitive forms for manual backup triggers, including source directory selection and Google Drive integration.
* **Search & Restore View:** Developed the "History" interface, allowing users to browse archived backups and initiate file restoration processes.
* **Technical Collaboration:** Managed the integration of frontend components with the Django backend, utilizing Git for version control and collaborative code management.

## Technical Highlights (UI/UX Focus)
* **Scheduling UI:** A comprehensive interface for defining backup cycles (daily/weekly) and execution times.
* **Status Monitoring Visuals:** Designed a clear notification and status system to inform users about the operational health of various modules.
* **Cross-Platform Compatibility:** Fully responsive layout designed for a seamless experience across different devices.
* **Personalization:** Implemented a system-wide Light/Dark mode toggle for improved accessibility.

## Tech Stack
* **Backend:** Python (Django)
* **Frontend:** HTML5, CSS3, JavaScript
* **Cloud API:** Google Drive API integration (UI layer)
* **Database:** SQLite
* **Tools:** Git, GitHub
